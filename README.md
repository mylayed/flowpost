# FlowPost — Telegram-бот автопостингу

Незалежний SaaS-бот для власників Telegram-каналів і груп: створення постів у зручному редакторі, відкладена публікація, ШІ-асистент, водяні знаки, мультипостинг і підписка на канали за Telegram Stars (пробний період на кожен канал, безкоштовний тариф і платні тарифи в Mini App «Білінг»).

## Можливості

| Розділ | Що реалізовано |
|---|---|
| Старт | Опис «Що вміє цей бот?» (uk/en), вітальне повідомлення з ілюстрацією, постійна reply-клавіатура з 6 кнопками, кнопка «Меню» зі списком команд |
| `/addchannel` | Нативний вибір чату (`request_chat`) з автоматичним додаванням бота в адміни; перевірка прав бота та користувача; автопідключення, якщо бота додали вручну; топіки форумних груп; сповіщення, якщо бот втратив права |
| Створення поста | Кнопка «Створити пост» або просто надіслати фото/відео/текст; альбоми; текст окремим повідомленням стає підписом; вибір каналу (1 канал обирається автоматично) |
| Редактор | Прев'ю «як у каналі» + панель: **Водяний знак, Кнопки, Медіа, Автопідпис, ШІ-асистент, Більше налаштувань, Повідомлення (серія), Автоповтор, Відкласти, Мультипостинг, Опублікувати, Скасувати і назад** |
| Відкласти | Перемикач дат «пт, 11 вер», список запланованого на день, сітка слотів із кроком 5 хв і «↓ Ще слоти», ручне введення «Година:Хвилини» з помилкою та прикладом, підтвердження |
| Контент-план | Пости по днях: редагувати, перенести, опублікувати зараз, скасувати |
| Редагувати пост | Список останніх постів або пересланий із каналу пост; зміни тексту/кнопок/медіа застосовуються до вже опублікованих повідомлень |
| Рекламний пост | Позначка «Реклама», без автопідпису, автовидалення через 24 год (усе змінюється) |
| Мої проєкти | Налаштування каналу: автопідпис, водяний знак, стиль ШІ, топік, відключення |
| Налаштування | Мова uk/en, часовий пояс, статус підписки, підтримка |
| Оплата | Telegram Mini App «Білінг»: баланс у Stars із кешбеком, тарифи й калькулятор, ліміти каналу, перенесення підписки; ліміт постів для кожного каналу, пейвол, `/paysupport`, `/terms` |
| Адмін | `/stats` (користувачі, підписки, конверсія, публікації, ШІ), `/grant`, `/expire` |

## Стек

Python 3.12 · aiogram 3.31 · SQLAlchemy 2 (async) + Alembic · PostgreSQL (SQLite для локальної розробки) · Redis (необов'язково) · Pillow + ffmpeg · Anthropic API (`claude-opus-5`) · aiohttp.

## Швидкий старт (локально, Windows)

1. Створіть бота в [@BotFather](https://t.me/BotFather) і скопіюйте токен.
2. Встановіть залежності:
   ```bash
   python -m venv .venv
   ```
   ```bash
   .venv\Scripts\pip install -r requirements-dev.txt
   ```
3. Скопіюйте `.env.example` у `.env` і вкажіть щонайменше `BOT_TOKEN` та `ADMIN_IDS`. Для ШІ додайте `ANTHROPIC_API_KEY`.
4. Запустіть (міграції БД застосуються автоматично; без `WEBHOOK_BASE_URL` бот працює через long polling):
   ```bash
   .venv\Scripts\python -m flowpost
   ```
5. Для водяних знаків на відео встановіть ffmpeg (`winget install ffmpeg`) і перезапустіть термінал.

Локально за замовчуванням використовується SQLite (`flowpost.db`). Щоб працювати з PostgreSQL і Redis, як у проді: `docker compose up -d postgres redis` і пропишіть `DATABASE_URL`/`REDIS_URL` у `.env`.

## Налаштування в @BotFather

- `/setdescriptionpic` — велика картинка над описом «Що вміє цей бот?» (Bot API не дозволяє встановити її програмно). Можна взяти `assets/start.png`.
- `/setuserpic` — аватар бота.
- Текст опису, короткий опис і список команд бот виставляє сам під час запуску (uk/en).

## Деплой на Railway

1. Створіть проєкт → **Deploy from GitHub repo** (репозиторій із цим кодом). Railway збере `Dockerfile` (з ffmpeg і шрифтами DejaVu).
2. Додайте сервіси **PostgreSQL** і (бажано) **Redis**.
3. У змінних бота:
   - `BOT_TOKEN`, `ADMIN_IDS`, `SUPPORT_CONTACT`
   - `DATABASE_URL=${{Postgres.DATABASE_URL}}`, `REDIS_URL=${{Redis.REDIS_URL}}`
   - `WEBHOOK_BASE_URL=https://<ваш-домен>.up.railway.app` (Settings → Networking → Generate Domain), `WEBHOOK_SECRET=<випадковий рядок>`
   - `ANTHROPIC_API_KEY`
4. Healthcheck — `/health` (див. `railway.json`). Бот сам реєструє webhook `…/tg/webhook`.

Render: той самий Dockerfile як Web Service, змінні ті ж; `PORT` Render задає сам.

## Оплата

**Mini App «Білінг» (Telegram Stars).** Кнопки «Оплатити підписку» відкривають Mini App за адресою `{WEBHOOK_BASE_URL}/app/` (Telegram вимагає HTTPS, тому потрібен публічний `WEBHOOK_BASE_URL` або `WEBAPP_URL`). Поповнення балансу йде через `createInvoiceLink` у валюті `XTR`; бот підтверджує `pre_checkout_query` і зараховує Stars та кешбек (`CASHBACK_PERCENT`) після `successful_payment`. Тарифи, знижки, пробний і безкоштовний тарифи та ціни пакетів задаються змінними з `.env.example`.

**Ліміти постів.** Кожен канал має власний тариф: платна підписка (N постів на добу), пробний період із першого підключення (`TRIAL_DAYS` днів і `TRIAL_POSTS` постів) або безкоштовний тариф (`FREE_POSTS_PER_DAY` на канал і на акаунт). Коли ліміт вичерпано, пост переноситься на наступну добу.

**LiqPay** лишився лише для підписок, оформлених раніше: бот обробляє їхні продовження через `POST {WEBHOOK_BASE_URL}/pay/liqpay/callback` і дозволяє вимкнути автопродовження.

Адмін-команди для тестування: `/grant <tg_id> <днів>` — видати/продовжити доступ, `/expire <tg_id>` — завершити доступ (перевірка пейволу).

## ШІ-асистент

Використовується Anthropic API, модель `claude-opus-5` (змінна `ANTHROPIC_MODEL`) з adaptive thinking і `effort` із `AI_EFFORT` (за замовчуванням `medium`). Увімкнені серверні fallback-и (`AI_FALLBACKS=true`): якщо модель відмовить, запит автоматично перезапуститься на резервній моделі. Доступні дії: оформити пост, скоротити, виправити помилки, додати емодзі, свій запит, пост зі скріншоту (vision). Для кожного каналу можна задати «стиль» — він додається до системного промпту. Денні ліміти: `AI_DAILY_LIMIT_TRIAL` / `AI_DAILY_LIMIT_PAID`.

## Обмеження Telegram, які враховано

- Під альбомом не можна показати inline-кнопки — текст і кнопки йдуть окремим повідомленням одразу після альбому.
- GIF не можна поєднувати з іншими медіа в альбомі.
- Підпис до медіа — до 1024 символів; довший текст автоматично виходить окремим повідомленням.
- Бот може завантажити файл лише до 20 МБ, тож більші відео публікуються без водяного знака (з попередженням).
- В опублікованому альбомі не можна змінити кількість медіа — при редагуванні оновлюється лише текст/медіа на місцях.

## Тести

```bash
.venv\Scripts\python -m pytest -q
```

Покривають парсери (кнопки, час, топіки), слоти та формат дат, HTML-санітайзер, автопідпис, правила медіа-груп, повноту перекладів, LiqPay (підпис, callback, ідемпотентність), логіку підписки, Mini App (initData, API, оплата Stars, ліміти, перенесення), ліміти постів каналів, відправку постів (текст, фото, альбом із кнопками, довгий підпис), воркер (публікація, автоповтор, пауза без підписки, пропущені, закріплення й автовидалення), водяні знаки та формат запиту до ШІ.

## Структура

```
flowpost/
  __main__.py          запуск: міграції, polling/webhook, HTTP-сервер, воркер
  config.py            налаштування з .env
  web.py               /health, LiqPay callback і підключення Mini App
  webapp/              Mini App «Білінг»: перевірка initData, JSON API, статичний фронтенд
  i18n/                uk.py, en.py — усі тексти інтерфейсу
  db/                  моделі, типи, сесії, репозиторії
  bot/
    setup.py           диспетчер, middleware, порядок роутерів, команди й опис
    middlewares/       сесія БД, користувач/мова, альбоми, пейвол
    keyboards/         головне меню, редактор, розклад
    handlers/          старт, меню, канали, створення поста, контент-план, проєкти,
                       налаштування, оплата, адмін
      editor/          кожна кнопка редактора — окремий модуль
  services/            publisher, delivery, worker, watermark, ai, billing, parsing, slots
alembic/               міграції
assets/                ілюстрації для /start і /addchannel (плейсхолдери — замініть на брендові)
tests/
```
